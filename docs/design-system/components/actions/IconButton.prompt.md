Icon-only square control for toolbars, headers and list rows. Always pass `aria-label`.

```jsx
<IconButton aria-label="Notificaciones"><BellIcon/></IconButton>
<IconButton variant="secondary" aria-label="Filtrar"><FilterIcon/></IconButton>
```

Variants `ghost` (default, muted icon), `secondary` (outlined), `primary` (brand fill — use rarely, e.g. a floating compose action). Sizes 34/44/52px.
